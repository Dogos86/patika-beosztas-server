# Legacy forrás helye

Másold ide a legfrissebb működő WinForms projektet:

```text
legacy/current-winforms/
  <solution és projektek>
```

Az audit fázis előtt:
- ne nevezd át tömegesen a fájlokat;
- ne módosítsd a működő algoritmust;
- ne töröld a JSON demóadatot, ha nem tartalmaz éles személyes adatot;
- valódi személyes adatot anonimizálj, mielőtt GitHubra kerül.

A Codex először felméri és buildeli, csak utána javasol migrációt.
